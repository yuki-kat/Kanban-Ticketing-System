# Kanban Ticketing System

An interactive Kanban-based IT ticketing and task management system built with **React** and **Vite**.

## Features

- **Kanban Board Layout**: Visualize tickets across custom workflow stages (e.g., To Do, In Progress, Done).
- **Ticket Management**: Create, update, assign, and manage IT support tickets efficiently.
- **Fast Development & Build**: Powered by Vite for fast HMR (Hot Module Replacement) and optimized production builds.

## Tech Stack

- **Frontend**: React, JavaScript (ES6+)
- **Build Tool**: Vite
- **Package Manager**: npm
